# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-08-08

### Added
- **Visual Workflow Builder**: Declarative ReactFlow-based drag-and-drop editor.
- **Runtime Engine**: Fault-tolerant execution engine with parallel/join capabilities.
- **Event Sourcing**: Deterministic execution journal for all state changes.
- **Replay & Recovery**: Dead-worker recovery, optimistic concurrency control, and DAG-based retry mechanisms.
- **Plugin SDK**: Dynamic registry for injecting new execution capabilities (HTTP, Script, AI, Email).
- **Execution Viewer**: Real-time observability dashboard with Gantt charts and timelines.
- **Operations Lab**: Automated distributed systems testing bed (Leader failovers, worker crashes).
- **Docker Compose**: 1-click infrastructure deployment.
- **GitHub Actions**: Modular CI/CD pipelines (Lint, Test, Release).
